# Self-hosted AI web interface for a NixOS home server

_Date: 2026-08-11. Sources are limited to official project documentation and repositories._

## Recommendation

**Choose Open WebUI.** It covers the important path—arbitrary OpenAI-compatible local servers, built-in multi-user access, document RAG, and MCP—in one application with one persistent state directory. That is the best Pareto fit for a home server: the broadest useful feature set without making PostgreSQL, object storage, or a separate RAG service mandatory.

For Balaur, connect it directly to the existing FastFlowLM endpoint at `http://127.0.0.1:8081/v1`. Prefer the native `services.open-webui` NixOS module already present in the pinned nixpkgs over introducing a container runtime solely for this service. Keep authentication enabled, bind Open WebUI to loopback, and expose it through the existing private Caddy ingress. Keep the module's default state under `/var/lib/open-webui` and add that path to the Borg backup; moving it under `/srv/app-data` would require deliberately arranging permissions for the module's dynamic service user.

**Runner-up: AnythingLLM** when shared document workspaces and agentic RAG matter more than a general-purpose chat UI. **LibreChat** is compelling when its richer authentication/access-control and MCP model justify more services. **LobeChat/LobeHub** has a polished feature set, but its full self-hosted knowledge-base stack is disproportionate for this requirement. No fifth option is clearly stronger enough to add.

## Privacy and security caveats

Self-hosting the UI does not by itself keep data local. Prompts, document chunks and tool arguments leave the server whenever a remote model, embedding service, web search, parser, or MCP server is selected. Keep all relevant providers local if that is the privacy boundary.

- **Open WebUI:** its own hardening guide says it is intended for private/trusted networks, does not terminate TLS, defaults CORS to `*`, and does not enable password-complexity checks by default. Restrict CORS, use HTTPS at the proxy, retain the default closed signup posture, and set a stable `WEBUI_SECRET_KEY`—especially for OAuth-backed MCP tokens ([hardening](https://docs.openwebui.com/getting-started/advanced-topics/hardening/), [MCP](https://docs.openwebui.com/features/extensibility/mcp/)). If Ollama is added later, note that it defaults to a 2,048-token context in the cited RAG guide, which can make retrieved content ineffective; increase it for document use ([RAG](https://docs.openwebui.com/features/chat-conversations/rag/)). The current license restricts changing Open WebUI branding only when a deployment exceeds 50 end users in a rolling 30-day period, so Balaur's personal deployment falls within its explicit exception; nixpkgs nevertheless classifies the package as unfree ([license](https://github.com/open-webui/open-webui/blob/main/LICENSE)).
- **AnythingLLM:** anonymous telemetry is enabled but can be disabled. Removing a document from a workspace removes that workspace's vectors but leaves the source in “My Documents” until it is separately deleted ([privacy/data](https://docs.anythingllm.com/features/privacy-and-data-handling/)). MCP stdio servers execute inside the application container and can access the mounted storage path, so only install trusted servers ([MCP on Docker](https://docs.anythingllm.com/mcp-compatibility/docker)).
- **LibreChat:** bootstrap the intended administrator before exposing the service. The default MongoDB container is not externally published, but database authentication is an optional hardening step rather than the basic default ([MongoDB auth](https://www.librechat.ai/docs/configuration/mongodb/mongodb_auth)). Per-user MCP isolation helps, but tools still receive whatever arguments and credentials users authorize.
- **LobeHub:** its Ollama guide demonstrates `OLLAMA_HOST=0.0.0.0` and `OLLAMA_ORIGINS=*`; do not copy that broad exposure onto an untrusted network. Prefer a private container network and a narrowly scoped origin ([Ollama](https://lobehub.com/docs/usage/providers/ollama)). Its MCP guide explicitly warns that malicious servers can perform unintended actions ([custom MCP](https://lobehub.com/docs/usage/community/custom-mcp)).

## Pareto deployment shape

For this server, the minimal durable design is **the existing FastFlowLM service + the native NixOS Open WebUI service + its persistent state directory + the existing private Caddy ingress**. Add no container runtime or external vector database initially. Reconsider AnythingLLM only if document workspaces become the dominant workflow; reconsider LibreChat only if granular shared-resource ACLs or its broader MCP transports become concrete requirements.
